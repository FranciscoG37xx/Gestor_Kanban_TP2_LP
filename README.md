# Kanban Task Manager

A desktop Kanban board application built in Java.

## Features
- create/edit/move/delete cards
- costumizable columns
- Task persistence via local file storage (`kanban_data.txt`)

## Tech Stack
- Java
- NetBeans / Ant build system

## How to Run
1. Clone the repository
2. Open the project in NetBeans (or run `ant run` from the project root)
